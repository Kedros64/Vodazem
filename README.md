# PRO Землю и Воду — vodazem.ru

Высококонверсионный одностраничный сайт компании **ООО «ЗИВ» (PRO Землю и Воду)** —
оформление прав пользования водными объектами и землёй «под ключ».

## Что внутри

- `index.html` — вёрстка страницы (семантический HTML, на русском, с SEO-метатегами и Open Graph).
- `assets/css/styles.css` — дизайн-система и стили (адаптив для десктопа, планшета и мобильных).
- `assets/js/script.js` — поведение: липкая шапка, мобильное меню, анимации появления, счётчики, обработка форм, аккордеон FAQ.
- `assets/img/` — изображения, сгенерированные через Higgsfield (Soul Location), и фирменный логотип.

## Структура сайта

1. **Hero** — заголовок, гарантия «получаем разрешение или возвращаем деньги», быстрая форма проверки объекта.
2. **Доверие** — опыт 10+ лет, «под ключ», вся Россия, бесплатная проверка.
3. **Услуги** — 7 направлений с ценами «от»: водопользование, сброс сточных вод, пруд/водохранилище, ГТС → Код ГТС, водозабор и выпуск, земельный участок, аренда акватории.
4. **Почему мы** — 6 преимуществ.
5. **Этапы** — процесс оформления и ориентировочные сроки.
6. **ГТС** — отдельный блок по легализации плотин и дамб.
7. **Применение** — сценарии использования.
8. **Стоимость** — поэтапная оплата, CTA.
9. **FAQ** — частые вопросы.
10. **Контакты** — форма заявки + телефон, e-mail, WhatsApp/Telegram.
11. **Подвал** — услуги, контакты, реквизиты ООО «ЗИВ».

## Запуск

Статический сайт без сборки. Откройте `index.html` в браузере или раздайте каталог любым
веб-сервером (`python3 -m http.server`, Nginx, GitHub Pages и т. п.).

## Подключение форм

Формы (`#quickform`, `#mainform`) сейчас работают в демо-режиме (см. комментарий в
`assets/js/script.js`). Для приёма заявок подключите отправку на бэкенд —
Telegram-бот, e-mail или CRM.
